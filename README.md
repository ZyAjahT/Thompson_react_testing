# Thompson_react_testing

While working on this project, I learned many testing strategies to complete my testing requirements. One stategy that has helped me during this project was writing down what test cases would be used for each function. I would determine the normal cases, egde cases, and boundary conditions that each function may have. This help me with me with not getting overwhelmed with how many test I would need to write and to keep an organize list of tasks that I can follow. 

The main thing I leerned while working on this project is that test handleing is alot more time-consuming and detailed than I thought. I would have never thought about test all these little scenarios or would have think it was a big deal to do so.
